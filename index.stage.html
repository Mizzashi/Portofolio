Mission 1

Sécurisation du compte local adminpc via Microsoft LAPS

Windows Server 2022 Active Directory Microsoft LAPS GPO DNS Sécurité des postes

Dans le cadre du renforcement de la sécurité des postes de travail, j'ai étudié et déployé Microsoft LAPS (Local Administrator Password Solution) dans un environnement Active Directory de test sous Windows Server 2022. L'objectif : automatiser la gestion du mot de passe du compte administrateur local adminpc, en générant un mot de passe unique, complexe et renouvelé automatiquement pour chaque poste — afin de limiter les risques de déplacement latéral en cas de compromission.

  • Création et configuration d'un contrôleur de domaine Active Directory (teste.mairie-bm.gp)
  • Installation de Microsoft LAPS et extension du schéma Active Directory
  • Création d'une OU dédiée et attribution des permissions de lecture/écriture
  • Configuration de la GPO LAPS (longueur, complexité, expiration à 30 jours)
  • Vérification du fonctionnement et récupération des mots de passe via PowerShell et LAPS UI
  • Renforcement complémentaire via les groupes restreints (Restricted Groups)
