Projet VLAN / Routage / Wi-Fi / RADIUS

Mise en place d’une infrastructure réseau avec segmentation en VLAN, routage inter-VLAN, Wi-Fi et authentification RADIUS.

Objectifs

  • Segmenter le réseau avec des VLAN (utilisateurs / admin / invités…)
  • Mettre en place le routage inter-VLAN
  • Déployer un accès Wi-Fi sécurisé
  • Authentifier via RADIUS (802.1X si applicable)
Ouvrir le dépôt sur GitHub

Compte-rendu du TP n°5 (BTS SIO 1ʳᵉ année) : déploiement d’un serveur DHCP sous Windows Server 2022 dans un environnement virtualisé (Proxmox VE), avec création des VM (SRVDHCP, station0, station1), configuration de l’étendue 192.168.20.10 → 192.168.20.254 (bail 8 jours, options passerelle/DNS/domaine), puis validation par ipconfig, ping et test d’arrêt du service, avec rappel du fonctionnement DHCP (DORA).
